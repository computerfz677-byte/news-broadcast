## 三、参照历史经验的投资策略

**核心矛盾：** 国内基本面全面确认回暖（物流+6.7%、电子/高端装备物流+10%、数字消费+8.7%、创新药出海600亿美元） + 江苏新质生产力顶层催化 vs 全球级外部冲击（**油价破100美元、美股连跌、美通胀预期跳升、俄禁汽油出口、欧盟滞胀警告**）。这是"内强外崩"的极端分化格局，历史上（2022年俄乌冲突同期）此类组合下A股呈现**结构性极端分化**：能源/黄金/军工独涨，成长与出口链承压。

**方向（按优先级）：**

1. **油气/黄金/军工 避险主线（进攻性对冲，15-20%）**——油价破100是2022年以来首次，参照2022年2-3月：布伦特破100后1个月内，A股油气、黄金、军工相对沪深300超额收益显著（中国石油区间涨幅超30%、黄金股普遍20%+）。建议作为"危机α"配置，**设置油价触发的纪律止盈**（若Brent回落至90以下减半）。军工因俄4月禁汽油出口+欧盟1.4万亿（3-27）防务开支，具备更长周期逻辑。
2. **江苏新质生产力/电子玻纤（进攻主线，15-20%）**——今日头条级催化，且是全球最紧缺的AI上游材料（低介电玻纤）产能落地。**历史经验**：2019年沪电股份因高频高速CCL需求爆发后1年涨数倍；本次"全球规模最大电子玻纤线点火"是供给侧的国产突破信号，中国巨石、中材科技、生益科技构成"玻纤-CCL-PCB"传导链。注意：该方向属成长，与油价/通胀交易部分对冲，建议与油气仓做**跷跷板配置**（油价涨则减成长、油价稳则加成长）。
3. **创新药出海（基本面主线，10-15%）**——对外授权超600亿美元是行业拐点级数据，参照2023-2024年ADC/GLP-1出海后恒瑞、百济的估值重塑。当前BD交易改善现金流预期，且创新药与油价/地缘低相关，是"内强"逻辑的纯正受益者。恒瑞医药、药明康德、泰格医药等。
4. **物流/消费（底仓，10%）**——物流+6.7%、网上零售+10.3%确认消费弱复苏，但受全球滞胀压制外需，以**内需型**快递（顺丰、圆通）与必选消费为主，回避出口占比高的家电/轻工。
5. **回避方向**：①出口链（家电、纺服、消费电子代工）——美消费者信心下滑+欧盟滞胀+汇率压力三重压制；②高估值纯AI概念股——全球流动性收紧预期下估值承压；③航空——油价破100成本端重创。

**节奏与风控：**
- 当前处"危机交易"窗口，波动率显著放大，**单方向仓位不宜超20%**，用油气/黄金对冲成长与消费。
- 油价是总开关：Brent站上100→加油气减成长；回落至90下方→减油气加成长（电子玻纤/创新药）。
- 外部事件（美以对伊行动"持续数周"、俄4月1日禁汽油出口生效）将主导下周波动，建议节前（清明）降低总敞口，节后视中东局势与国内增量政策兑现再加仓。
