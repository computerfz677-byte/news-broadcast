**原文/要点：**

央视网消息（新闻联播）：中共中央总书记、国家主席、中央军委主席习近平7日下午在出席十四届全国人大四次会议解放军和武警部队代表团全体会议时强调，"十五五"时期要如期实现建军一百年奋斗目标、高质量推进国防和军队现代化，必须坚持好、运用好、发展好政治建军这个重要法宝，毫不动摇坚持和加强党对军队绝对领导，充分发挥政治建军特有优势，凝心聚力推动国防和军队现代化行稳致远。

会上，孙雷、周芬、唐武祥、郝井文、姜晓栋、朱悦萌等6位代表先后发言，分别就跨军地执法协作、党组织领导科研攻坚、军士人才培养、新装备新力量能力生成和运用、弘扬优良传统、典型培树宣传和学习运用等提出意见建议。

在认真听取代表发言后，习近平发表重要讲话。他指出，党的十八大以来，党中央领导人民军队以前所未有的决心和力度深化政治整训、推进政治建军，取得重大成效。军队是拿枪杆子的，军中绝不能有对党怀有二心之人，绝不能有腐败分子藏身之地，必须坚定不移推进反腐败斗争。**"十五五"一开局就要立起从严监管硬规矩，紧盯资金流向、权力运行和质量管控等关键环节，加强重大项目监管，强化军地融合监督，确保在监管前提下搞建设。要推进军费预算管理改革，搞好军费供需动态平衡，强化经费使用全链条管控和绩效评估，把每一分钱都用在刀刃上。**

习近平强调，完成"十五五"时期国防和军队现代化目标任务，归根到底要靠各级党组织来领导和推进。要全面加强我军党的领导和党的建设，选准配强高层党委班子，增强基层党组织自主抓建能力。要坚持党管军事、党管干部、党管行业，提高科学决策能力，在攻坚重大任务、化解突出矛盾、解决发展难题过程中发挥关键作用，把党的领导优势转化为发展优势。

习近平指出，要加强革命化专业化人才队伍建设，坚持不懈用党的创新理论铸魂育人，确保现代化武器装备掌握在革命化人才队伍中。要完善促进人才发展的制度和条件，**体系推进联合作战指挥、新型作战力量、高层次科技创新、高水平战略管理"四类人才"培养**，实现人的能力素质同强军实践协调发展。

习近平强调，要大力传承和弘扬我党我军优良传统，推进新时代强军文化建设，加强先进典型培养和激励。要把基层作为赓续优良传统的沃土，把部队建设和战斗力基础打得更加牢靠。中央军委副主席张升民参加会议。

**A股关联分析：利好（军工装备主线，中期确定性 > 短期弹性）**

本条为当日最高政治权重条目，也是军工板块年度级别的政策定调。三个可交易的增量信息：

1. **"十五五"开局与建军百年目标绑定**——2027年建军一百年奋斗目标进入最后冲刺，2026—2027年是装备交付与订单确认的密集兑现期，行业景气度的时间确定性极高。
2. **"军费预算管理改革""经费使用全链条管控和绩效评估""把每一分钱都用在刀刃上"**——这是本次讲话中对产业链影响最直接的一句。含义是双向的：一方面军费总量增速可能不再单边扩张（2026年国防预算增速已于3月5日落地），另一方面**支出结构将向实战化、高价值、可验证效能的方向大幅倾斜**。这意味着"低效摊派型采购"受压、"关键战力型装备"受益，板块内部将出现显著分化，主战装备总装、新型作战力量（无人化、电子战、太空/网络）优于传统低端配套。
3. **"新装备新力量能力生成和运用""四类人才"体系培养**——官方首次在联播口径中把"新型作战力量"与"高层次科技创新"并列为人才培养重点，指向无人机/无人艇、军用AI、电子对抗、卫星互联网军事应用等新域新质方向。
4. **反腐与从严监管强化**——短期看，军队反腐深化可能对订单节奏形成扰动（历史上军改与反腐期均出现过订单确认延迟），但中长期看有利于清理低效供应商、提升合规龙头的份额集中度。**这一条是本次讲话中唯一需要警惕的负向因子**：不宜把军工当作单纯的政策直线利好，节奏比方向更重要。

叠加条目16的中东战事，军工在本日形成"内政定调 + 外部实战验证"的双重催化，是当日最强的交叉主线。

### 条目2：【总书记与我们在一起】建设健康中国 增进民生福祉

**原文/要点：**

央视网消息（新闻联播）：习近平总书记在看望参加全国政协十四届四次会议的农工党、九三学社、医药卫生界、社会福利和社会保障界委员并参加联组会时强调，要坚定不移走中国特色卫生与健康发展道路，推动"十五五"时期健康中国建设取得决定性进展。总书记的重要讲话在全国政协委员当中引发热烈反响，大家表示要用好专业优势，贡献智慧力量，在建设健康中国、增进民生福祉的生动实践中展现新作为。

6日下午，农工党、九三学社、医药卫生界、社会福利和社会保障界委员用热烈掌声欢迎习近平总书记到来。六位委员分别从战略规划、基层服务、创新驱动等方面提出意见建议。

巴桑卓玛委员来自雪域高原的医疗一线，她向总书记介绍了在党中央关怀下，高原病防治工作取得的显著成效。在巴桑卓玛委员所在的西藏自治区第二人民医院，今天（3月7日）上午刚刚完成一场远程医疗协作，指导山南市桑日县医院的医生制定诊疗方案。如今，西藏已建立并完善覆盖城乡的公共医疗卫生服务体系，**实现紧密型县域医共体全覆盖**。

习近平总书记在讲话中强调，**到2035年建成健康中国是中共中央作出的一项战略决策，"十五五"是实现这一目标的关键时期，必须统筹谋划、加紧推进，力求取得决定性进展**。

习近平总书记指出，建设健康中国是一项系统工程。面对人民群众日益增长的多元化卫生健康需求，必须突出重点，紧紧抓住那些惠及面广、牵一发而动全身的工作，**在健全公共卫生体系、建设优质高效医疗服务体系、倡导健康文明生活方式等方面集中力量和资源**，采取有效措施加以推动，不断取得新的成效。

（据人民日报同日报道补充）习近平强调，要健全党委统一领导、党政齐抓共管的工作格局，完善健康促进政策制度体系。进一步深化改革，**完善医疗、医保、医药协同发展和治理机制**。推动科技创新成果转化运用，**推进全民健康数智化建设**。加强卫生健康行业党建工作，调动广大医务人员的积极性主动性创造性，加大人才培养力度，弘扬优良医德医风，着力营造风清气正的行业环境。

"三八"国际劳动妇女节即将到来，联组会上，习近平总书记代表中共中央，向全国各族各界妇女、海内外女同胞女侨胞致以节日祝福和美好祝愿。

**A股关联分析：利好（医药医疗，政策口径边际转暖的延续确认）**

本条是3月6日联组会讲话的舆论发酵与二次强化，属于"政策信号的第二落点"。对A股医药板块的意义在于三点：

1. **"决定性进展"是罕见的强表述**。健康中国2030目标此前多用"扎实推进""持续改善"，此次直接定调"十五五"必须取得"决定性进展"，意味着后续五年医疗卫生领域的财政投入强度与政策优先级将系统性抬升，这是对过去三年医药板块受集采、反腐、控费压制的估值逻辑的重要对冲。
2. **"全民健康数智化建设"为首次出现的新提法**。这是本条最具增量的关键词，直接指向医疗信息化、AI辅助诊断、电子病历互联互通、区域健康信息平台的新一轮建设周期。医疗IT板块在经历2023—2025年订单低谷后，具备明确的政策催化。
3. **"三医协同"（医疗、医保、医药协同发展和治理机制）**——重申协同而非单向控费，暗示医保政策从"极限压价"向"腾笼换鸟、支持创新"过渡，利好创新药与创新器械。
4. **"紧密型县域医共体"在西藏实现全覆盖的案例展示**，与条目11卫健委"十五五谋划1000个左右紧密型县域医共体"形成呼应，指向县域医疗设备的新一轮扩容采购（基层影像、检验、内镜、监护）。

需要提示：医药板块的政策转暖是"斜率修复"而非"V型反转"，公益性定调（"始终坚持基本医疗卫生事业的公益性"）意味着行业整体毛利中枢难以大幅回升，超额收益应来自结构（创新、设备更新、数智化）而非总量。
