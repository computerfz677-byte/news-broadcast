## 三、参照历史经验的投资策略

**方向排序（强→弱）**

1. **出口链（电力设备 + 工程机械 + 家电 + 跨境物流）——本日最强主线，建议作为核心配置。**
   历史经验：2021年Q1、2024年Q1两次外贸数据大超预期后，出口链龙头在数据公布后的10-15个交易日内平均跑赢沪深300约5-8个百分点，且机电类（电力设备、工程机械）弹性显著大于纺服等劳动密集品。本次机电占比63.4%、增速18.3%，结构比总量更值得重视。**策略**：以正泰电器、三一重工、美的集团构建出口链组合，仓位可给到20-25%，持有周期1-2个季度，跟踪月度出口数据（若单月增速跌破8%则减仓）。

2. **中欧关系缓和（新能源车 + 光伏 + 汽零）——政策风险溢价修复，中期布局。**
   历史经验：欧盟对华电动车关税议题每次出现缓和表态，比亚迪、宁德时代等平均有3-5%的脉冲反弹，但真正的趋势性修复需等到关税实质性调整。**策略**：把西班牙表态视为"风向标而非发令枪"，逢回调分批建仓新能源车出海标的，避免一次性重仓；关注后续欧盟层面是否跟进。

3. **地缘避险（油运 + 黄金）——已兑现，转为减仓思路。**
   历史经验：封锁类事件从"宣称"到"生效"，股价往往在"宣称日"完成主升，"生效日"反而是获利了结点（2019年霍尔木兹、2023-24红海危机均如此）。叠加中方明确促和、多方反对封锁，外交降温概率上升。**策略**：昨日介入的地缘仓位建议在本日兑现一半，保留黄金作为长期对冲底仓（≤5%），不新增油运追高。

4. **春耕链（钾肥 + 磷肥 + 节水灌溉）——季节性行情，短线1-2周。**
   历史经验：春灌数据披露期（3月下旬-4月中旬）是化肥板块季节性高点区间，通常在4月底前后随春耕结束而回落。**策略**：短线参与、五一前了结，不做中线持有。

5. **川藏铁路与商业航天（铁路基建 + 卫星）——事件催化型，观察为主。**
   历史经验：周年纪念类报道对铁路基建的催化通常只有1-2天，真正驱动是新开工批复；商业航天则受发射节奏影响、脉冲明显。**策略**：仅做题材观察，不作为主仓，等待川藏铁路新标段招标或密集发射窗口再介入。

**仓位与风控建议**
- 建议**提升至中高仓位（6-7成）**：外贸数据超预期+进口增速快于出口（内需回暖信号），基本面支撑较昨日明显增强。
- **核心25%**配置出口链；**中线20%**布局中欧缓和的新能源出海；**短线10%**做春耕季节性；**底仓剩余**留高股息与黄金对冲。
- **规避/减仓**：昨日的油运与油价弹性品种（事件已兑现，双向风险大）；单纯依赖题材周年报道的铁路基建脉冲。
