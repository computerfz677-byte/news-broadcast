## 三、参照历史经验的投资策略

**核心矛盾：** 今日出现**两条全新的重量级主线**（世界数据组织=数据要素国际化、深远海风电首次入规划），同时**中东进入"谈判预期 vs 哈尔克岛作战风险"的极端对赌**。这是"主线更清晰、外部更极端"的组合。

**方向（按优先级）：**

1. **数据要素（今日最强新主线，20%）**——**世界数据组织总部落地北京**是历史级事件，中国首次在全球数据治理规则制定中取得主导地位。历史对标：2022年12月"数据二十条"发布后数据要素板块2个月内龙头涨幅普遍80%+；2023年10月国家数据局挂牌后再度脉冲。**本次是"国际组织"级别，量级不低于前两次**，且丁薛祥"三个高"给出了清晰的选股框架（流通/赋能/安全）。建议**优先配置数据安全（山石网科、安恒信息）与数据流通基础设施（宝信软件、神州信息）**，因为"数据跨境流动"必然先解决安全合规。
2. **深远海风电产业链（今日次强新主线，15-20%）**——"首次写入规划+1亿千瓦装机翻番+1700亿风机/2200亿海工/5000公里海缆"是极其罕见的**三重量化**表述。历史对标：2021年"双碳"后海风产业链1年涨超100%，**海缆（东方电缆）因壁垒最高涨幅居首**。深远海（水深>50米、离岸70公里）比近海技术门槛更高，**海缆与海工装备（安装船、漂浮式基础）的壁垒溢价将更显著**。建议：东方电缆/中天科技（海缆）为核心，振华重工/中国船舶（海工装备）为弹性，明阳智能（漂浮式）为整机首选。
3. **两岸主题（日历型事件，5-8%，仅波段）**——**4月7-12日郑丽文访陆**是明确的时间窗口。历史经验：两岸高层互访前的**5-10个交易日**是主题活跃期，事件发生当日往往是高点。建议在4月初（3月31日-4月3日）建仓平潭发展等纯正标的，**4月7日访问开始后逐步兑现**，切勿在访问期间追高。这是典型的"买预期、卖事实"。
4. **军工（中期主线，10-15%）**——今日新增**以色列国防预算3200亿人民币创新高**，与美军弹药缺口、北约1.4万亿构成三重印证。这已不是事件驱动而是**全球军备扩张的产能周期**。持有期建议拉长至半年以上，不因中东谈判进展而减仓。
5. **消博会+海南（日历型，5%）**——4月13-18日消博会，历史上海南板块提前5-8个交易日预热。可在4月初布局中国中免、海南机场，开幕当周兑现。
6. **油气（对冲仓降至8-10%，双向止损）**——**风险收益比已恶化**：向上有哈尔克岛/霍尔木兹被列为作战目标的极端上行风险（油价可能冲击120-150美元），向下有特朗普"谈判进展顺利"+四国外长促谈的快速回落风险。建议**降低仓位、设置双向止损**，不做单边重仓。若哈尔克岛遇袭消息确认，则可快速加仓。
7. **回避**：航空（油价+夏秋航季无增量）、出口至欧美的消费品、高估值无业绩支撑的纯AI概念。

**仓位与节奏：**
- 建议配置：数据要素20% / 深远海风电18% / 军工12% / 两岸主题6% / 消博会海南5% / 油气黄金对冲10% / 现金29%（应对清明假期外盘风险）。

- **关键跟踪触发点**：①哈尔克岛/霍尔木兹是否遭实质打击（决定油价方向）；②美伊间接谈判是否有实质进展（决定风险偏好）；③世界数据组织后续是否有配套政策（数据跨境流动试点、数据资产入表细则）；④深远海风电首批项目招标（决定海风主线能否从主题转趋势）。
