## 三、参照历史经验的投资策略

**方向排序（强→弱）**

1. **地缘避险（黄金 + 油气 + 油运 + 军工）——短线弹性最大，但需快进快出。**
   历史经验：2019年霍尔木兹油轮事件、2022年俄乌冲突、2024年红海危机，A股同类映射均呈现"事件首日油运/黄金强、3-5个交易日达峰、随后随局势缓和快速回落"的节奏。**策略**：以不超过总仓位10%参与，油运（招商轮船）优先于石油开采（弹性更大），黄金作为对冲底仓可持有更久；一旦出现"谈判/降级"表述即减仓，不做隔夜加仓。

2. **服务业扩能提质（人力资源服务 + 检验检测 + 企业软件）——中期政策主线，逢回调分批。**
   历史经验：产业政策首提"XX行动"的板块，通常首日情绪脉冲（+3~8%），随后2-4周回落至起涨点附近，真正的第二波要等专项配套政策或试点名单落地。**策略**：不追首日高开，等首波脉冲回落后在10日线附近分批建仓，持有周期以季度计，重点看企业B端服务收入占比是否真实提升。

3. **中东能源合作出海（储能 + 氢能 + 新能源车 + 油气EPC）——订单驱动，跟单不跟嘴。**
   历史经验：中沙、中阿合作会谈后的储能与光伏出海标的，往往在"实际签约公告"日才出现主升，会谈日仅小幅反应。**策略**：把中海油服、中国电建、宁德时代放入观察池，等待具体项目中标/签约公告再介入，避免会谈日盲目追高。

4. **海南自贸港 + 消博会（免税 + 机场 + 海南本地）——事件驱动的区域主题，节奏性做波段。**
   历史经验：海南板块对"封关时间点临近"高度敏感，每逢政策节点前1-2周启动、消息落地当日见顶（"利好兑现即卖出"特征极其稳定）。**策略**：政策节点前布局、落地日兑现，切忌在消博会开幕当日追涨。

5. **分级诊疗（医疗信息化 + 基层设备）——慢变量，适合底仓配置。**
   历史经验：医疗信息化受财政采购节奏影响，政策发布到订单落地通常滞后1-2个季度，股价往往在半年报/三季报订单数据验证时才走强。**策略**：作为底仓小比例配置（≤5%），关注中标公告与在手订单。

**仓位与风控建议**
- 总体建议**中性仓位（5-6成）**：社融平稳但未加速，属"不差不强"环境，缺乏系统性行情基础，指数以结构性机会为主。
- **短线20%**做地缘避险与外贸物流的事件弹性；**中线30%**布局服务业扩能提质与能源出海；**底仓剩余**配置低利率受益的核心资产与高股息。
- **规避**：地方文旅、市政园林类政绩工程依赖型标的（财政纪律收紧信号明确）；强打赏依赖的中小内容平台（新规压制）。
- **风控红线**：地缘题材单只不超过总仓位3%，出现"停火/谈判"关键词立即离场；避免在消博会、广交会等展会开幕当日追高相关概念。
