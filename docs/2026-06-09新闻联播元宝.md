## 三、参照历史经验的投资策略

**历史经验参照：**
- **高层出访收官类事件**：历史上（如2019年访朝、历次中亚/中东出访）相关主题股多在出访前后1-2个交易日形成脉冲行情，出访结束后3-5日内主题热度衰减约50%-70%。真正能延续的是有实际协议落地的板块（口岸复通、基建订单）。
- **外贸数据超预期**：2021年、2024年多次出口高增月份后，汽车出口链与船舶板块相对收益显著且持续时间较长（1-3个月），因其业绩可验证性强，属"数据驱动"而非"事件驱动"。
- **区域发展调研（新疆/东北）**：政策调研后区域基建股平均有3-8个交易日的主题活跃期，但兑现率取决于后续是否有具体投资规划落地。

**可操作策略建议：**

| 维度 | 建议 |
|------|------|
| **仓位** | 维持中性偏积极，建议权益仓位6-7成。外贸数据支撑基本面，但地缘不确定性犹存，不宜满仓 |
| **方向（核心）** | 优先配置**业绩可验证的出口链**：汽车出口（比亚迪、上汽）、船舶（中国船舶）、航运（中远海控）。这类标的有实际数据支撑，回撤风险相对可控 |
| **方向（主题）** | 中朝合作、新疆基建属**事件驱动型主题**，建议小仓位（不超过2成）参与，快进快出 |
| **节奏** | 出口链可逢回调分批建仓，持有周期1-3个月；主题类建议在消息发酵首日介入、3-5个交易日内了结 |
| **风险控制** | 1）中东局势若升级，油价上行将压制中下游制造业毛利，需关注航空、化工的成本端压力；2）外交主题股常有"利好兑现即回落"特征，切忌追高；3）关注美伊谈判进展对全球风险偏好的扰动 |

**规避提示：** 对纯"蹭概念"、无实际业务关联的边贸/东北亚主题小盘股保持警惕，此类标的在主题降温后回撤幅度往往超过涨幅。
