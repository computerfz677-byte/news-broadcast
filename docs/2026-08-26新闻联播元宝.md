1. **习近平对西藏日喀则市吉隆县遭受泥石流灾害作出重要指示强调 千方百计搜救失联人员 加强各类风险隐患排查整治 确保人民群众生命财产安全 李强作出批示**
   8月26日10时30分许，因尼泊尔一侧发生泥石流灾害，造成西藏日喀则市吉隆县吉隆口岸重大人员伤亡、失联。
   灾害发生后，中共中央总书记、国家主席、中央军委主席习近平高度重视并作出重要指示指出，当务之急要千方百计搜救失联人员，转移安置受威胁群众，抓紧救治伤员，最大限度减少人员伤亡。要加强监测预警，注重科学施救，防止发生次生灾害。
   习近平强调，当前正处防汛关键期，各地区和有关部门要坚持极限思维、底线思维，认真落实防汛防台风各项措施，加强各类风险隐患排查整治，坚决防范重特大灾害事故发生，确保人民群众生命财产安全。
   中共中央政治局常委、国务院总理李强作出批示指出，要抓紧核清失联受灾人数，组织力量全力开展抢险救援，及时有序转移受险群众，同时注意科学施救，严防次生灾害。外交部要加强与有关国家沟通协调，及时通报情况，共同妥善做好救援处置工作。当前仍值主汛期，国家防办、防减救灾办要指导各地深入排查灾害风险隐患，加强险情监测预警和排险避灾，确保人民群众生命安全。
   根据习近平重要指示和李强要求，中共中央政治局委员、国务院副总理张国清率有关部门负责同志赶赴现场指导救援处置工作。西藏已组织力量全力做好现场搜救等工作。目前，有关工作正在进行中。

3. **李强在黑龙江、吉林调研**
   中共中央政治局常委、国务院总理李强8月24日至26日在黑龙江、吉林调研。他强调，要深入贯彻落实习近平总书记关于"三农"工作的重要论述和保障国家粮食安全的重要指示精神，以发展现代化大农业为主攻方向，坚持产量产能、生产生态、增产增收一起抓，多措并举全力夺取秋粮丰收，持续提升农业综合生产能力，确保粮食等重要农产品稳定安全供给。
   在黑龙江佳木斯，李强来到北大荒集团七星农场，走进旱作农田、万亩大地号水稻田，察看大豆、玉米、水稻长势。他强调，中国人的饭碗任何时候都要牢牢端在自己手上。秋粮是全年粮食生产大头，要加强田间管理，强化各项政策支持，确保秋粮和全年粮食丰收。在建三江国家农业科技园区、黑龙江农科院水稻所，李强详细询问种业创新和黑土地保护情况。他指出，提高粮食产量出路在科技。要深入推进良种培育，实施跨学科攻关，加强高端农机装备研制推广，加快人工智能运用和智慧农业发展。要积极采用工程、农艺、生物等措施，把黑土地保护好利用好，促进良田良种良机良法集成增效。在黑龙江省粮食产能提升重大水利工程项目现场，李强察看施工进展。他说，要加快工程建设，更好发挥防洪、灌溉、生态等综合功能，加强现代化灌区建设改造，努力实现旱涝保收，高产稳产。
   在吉林松原，李强来到宁江区德智农业专业合作社，细致询问经营情况。他指出，要发展多种形式的农业适度规模经营，完善农业社会化服务体系，积极拓展联农带农渠道，促进小农户与现代农业发展有机衔接。在吉林旭鑫油脂有限公司，李强察看玉米油生产线，了解产品销售情况。他强调，要大力发展农产品精深加工，做好"粮头食尾""农头工尾"转化增值文章，打造特色品牌，延伸产业链、提升价值链，增强就业吸纳能力，提高农业产业化水平。要严把食品质量安全关，紧盯生产、收购、加工、流通等关键环节，加强从农田到餐桌的全链条监管，让群众吃得放心、健康。李强来到查干湖，听取生态渔业等介绍。他指出，要践行大食物观，积极发展现代生态养殖，推动农林牧渔多业并举，促进生态旅游等多业态发展。
   吴政隆陪同调研。

4. **赵乐际同全国人大常委会会议列席代表座谈**
   中共中央政治局常委、全国人大常委会委员长赵乐际26日上午同列席十四届全国人大常委会第二十四次会议的全国人大代表座谈交流。他强调，要认真学习贯彻习近平总书记关于"三农"工作的重要论述和党中央决策部署，密切联系群众，发挥专业特长，履行代表职责，为持续巩固拓展脱贫攻坚成果、扎实推进乡村全面振兴作出新贡献。
   座谈会上，代表们围绕本次常委会会议审议关于持续巩固拓展脱贫攻坚成果、扎实推进乡村全面振兴工作情况的报告，结合履职作了发言。赵乐际认真倾听，同代表深入交流。他说，党的十八大以来，以习近平同志为核心的党中央团结带领人民打赢脱贫攻坚战，创造了举世瞩目的减贫奇迹。从2021年到2025年设立5年过渡期，推动巩固拓展脱贫攻坚成果同乡村振兴有效衔接，使脱贫基础更加稳固、成效更可持续。
   赵乐际指出，人大代表要围绕落实"十五五"规划纲要确定的涉农重要举措，结合常委会立法、监督工作安排，深入调研、积极建言献策，从法律和制度层面提出意见建议。赵乐际指出，人大代表要立足本职岗位担当实干。来自农业农村一线的代表要认真做好本职工作，带动群众因地制宜发展生产、增收致富。其他行业和领域的代表也要关心支持农业农村发展，共同推动农民富、农业强、农村美。赵乐际强调，人大代表要自觉当好党和国家联系人民群众的桥梁，更好接地气、察民情、聚民智、惠民生。模范遵守宪法法律，积极参与农村法治宣传教育，弘扬良好乡风民风。
   李鸿忠主持座谈会。

## 五、参照历史经验的投资策略

**一、可参照的历史行情逻辑**

1. **"十五五"开年首份产业发布会行情**：2021年底中央经济工作会议与2022年"稳增长"主线切换时，工业母机、工业互联网、"东数西算"均出现主题性脉冲行情；2023年工信部"两化融合/新型工业化"文件发布后，工业母机与机器人板块出现1—2周级别的量价齐升。本次第11条是"十五五"开局之年首次由国新办专场发布会**明确给出支柱/未来产业完整名单**，政策层级高于一般部委表态，具备同类事件驱动属性。
2. **电网投资量化目标 = 订单可测算行情**：2022年"加快建设新型电力系统"、2023年特高压"十四五"规划目标（"三交九直"）公布后，特高压板块均出现跨月级别行情，且行情强度与"新增直流回路数/投资额"这类**可量化目标**高度相关。本次给出"跨区直流+15回、跨省区输电5亿千瓦、抽蓄>1.2亿千瓦、配网+9亿千伏安"等硬指标，属同一类型的强催化。
3. **渗透率跨过阈值后的第二阶段**：北斗在重点行业渗透率已达90%以上，参考智能手机北斗标配（超98%出货支持）后产业链从"政策试点补贴"转为"存量替换+增量应用"；参考2019—2020年北斗专项建设与2021年"规模应用试点"后的订单节奏，**渗透率90%之后的增量来自工业制造与融合创新领域**，而非试点城市补贴。
4. **"反内卷"+产能治理的行业修复**：2023年底光伏、2024年锂电行业自律限产阶段，龙头集中度提升后盈利底部往往伴随政策表态而先行修复，龙头股先于行业价格反弹。本次第11条提及"综合整治'内卷式'竞争、健全产能监测预警机制"，属中期供给侧变量。
5. **地缘"降温但未解决"的资源品定价**：2024年4—6月中东冲突升级期间，油运（霍尔木兹绕行）与黄金同步走强，但海峡一旦出现"通航框架"，运价回落而油轮股仍受"合规运力稀缺"支撑。本次"临时航运走廊+仅允许商船通行"即属"通航部分恢复、风险溢价未清"的典型状态。

**二、可操作策略**

- **仓位**：**中性偏积极（5.5—6成）**。当日市场缩量（成交1.81万亿、环比减约230亿）且热点快速轮动，非银、有色领涨而计算机、电子、机械设备走弱，说明资金更偏好"有政策且有业绩/商品价格验证"的硬资产与低估值权重，成长主题当日已被部分兑现，**不宜在政策发布会次日追高纯概念成长股**。建议底仓放在"政策+订单"双验证的方向（电网设备、北斗），卫星仓做主题交易。
- **方向（优先级排序）**：
  1. **主线一：特高压/新型电力系统**（中国西电、国电南瑞）——"十五五"5亿千瓦跨省区输电能力是最硬的量化产业目标，确定性最高，宜作为核心仓位；
  2. **主线二：新型工业化配套**（比亚迪、中兴通讯）——智能网联新能源车"十五五"规划即将出台、6G列为重中之重，两个催化点有明确时间窗口，适合在政策正式落地前后分两段布局；
  3. **卫星方向一：北斗时空信息**（北斗星通、华测导航）——渗透率90%后的应用深化期，弹性来自工业制造领域扩容；
  4. **卫星方向二：具身智能/低空经济**（机器人、中信海直）——弹性最大但兑现最慢，**只做小仓位事件交易，不做底仓**；
  5. **防御/对冲配置**：种业（隆平高科）与农业链对应李强调研的确定性政策方向；黄金与油运可作为地缘反复的小比例对冲（当日有色板块已明显走强，需防高位追涨）。
- **节奏**：
  - T+1 开盘先看资金确认：若特高压/电网方向放量领涨，则说明市场在交易"5亿千瓦"这个可测算目标，可顺势持有2—3个交易日的趋势段；
  - 若开盘30分钟内市场继续由大金融/有色主导而科技成长走弱（延续8月26日盘面格局），则**降低成长主题仓位**，把权重移到电网设备与种业；
  - 具身智能、量子、低空等纯主题：只在盘中放量突破时参与，T+2 不及预期即离场，快进快出；
  - 《智能网联新能源汽车产业发展"十五五"规划》与《促进中小企业发展"十五五"规划》发布前后为主要加仓窗口，政策落地即兑现则卖出。
