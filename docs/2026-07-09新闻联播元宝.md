## 四、方法论与数据可靠性说明

本篇与前期部分简报在标的口径上有明显差异，需要说明原因：

在生成本篇过程中，对拟列出的个股代码进行抽样核验（9只），发现**6只存在问题**：

| 问题类型 | 实例 |
|----------|------|
| **已终止上市** | 600270 外运发展（中外运空运发展）上市状态已为"终止" |
| **证券简称已变更** | 002960 青鸟消防→**青鸟智控**（2026年2月）；002060 粤水电→**广东建工** |
| **主营已根本变更** | 600292 远达环保→**电投水电**，主营转为水电及生态治理，不再适用于 CCUS 逻辑 |
| **板块标签错配** | 300832 新产业实为化学发光 IVD 企业，非"科研级仪器"；601007 金陵饭店为酒店餐饮企业，不宜作为"养老服务"代表标的 |

抽检错误率约 67%，其中包含**推荐已退市股票**这一严重错误。据此判断：在不逐一核验的前提下批量生成"代码+名称+板块"三元组，会系统性地产出错误的金融事实数据。此类数据一旦进入知识库，后续检索时会被当作已核实信息使用，危害大于没有数据。

因此本篇采取的口径为：**核验过的给代码，没核验的只给方向**。这一取舍会降低表面上的"可操作性"，但保证了所列信息的可靠性。
