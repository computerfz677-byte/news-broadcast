**原文/要点：** 中共中央总书记、国家主席、中央军委主席习近平近日对常态化做好东西部协作工作作出重要指示指出，东西部协作开展30年来，在助力脱贫攻坚、促进区域协调发展等方面发挥了重要作用，彰显了我们党的政治优势和我国社会主义制度的优越性。习近平强调，今年是"十五五"开局之年，也是开展常态化帮扶第一年。要总结运用闽宁协作等有益经验，进一步完善协作机制，优化协作方式，拓展协作领域，推动东西部产业互补、人员互动、技术互学、观念互通、作风互鉴，实现互利共赢、共同发展。各级党委和政府要认真落实常态化帮扶责任，坚决守牢不发生规模性返贫致贫底线，扎实推进乡村全面振兴，不断增强区域发展协调性。全国东西部协作工作会议17日在宁夏银川召开，中共中央政治局委员、国务院副总理刘国中出席会议并讲话，强调要深化东西部产业合作、劳务协作，加强干部人才交流，拓展科技、金融等协作。

**原文/要点：** 日前，国务院印发《实施就业优先战略"十五五"规划》，明确了"十五五"时期深入实施就业优先战略、促进高质量充分就业的思路目标、重点任务和政策举措。《规划》聚焦促进高质量充分就业目标，提出"十五五"时期，就业保持总体稳定，就业机会更加充分，就业环境更加公平，就业结构更加优化，人岗匹配更加高效，劳动关系更加和谐。《规划》部署了强化宏观调控就业优先导向、加强产业和就业协同、拓展高校毕业生等青年就业成才渠道、加大对农民工等重点群体就业支持力度、推动灵活就业和新就业形态健康发展、加强劳动者就业权益保障等9方面重点任务。

### 条目6：全国麦收进度过九成 夏粮丰收已成定局

**原文/要点：** 记者今天（6月17日）从农业农村部了解到，目前全国麦收进度过九成，夏粮丰收已成定局。夏粮产量占全年粮食总产量的21%，其中小麦产量占夏粮产量的九成以上。我国冬小麦常年种植面积保持在3.4亿亩左右。针对去年秋季连阴雨造成的大面积晚播影响，主产区积极落实抗湿播种和晚播应变技术，基本实现应播尽播。在全国产粮大县山东郓城，144万亩冬小麦正加紧收获，当地收割机新增智能损失监测系统，机收损失率降到0.7%左右，收割一亩地少丢10—15公斤粮。今年"三夏"期间，全国投入各类农机具超1700万台（套），其中联合收割机80余万台。面对湖北麦区多轮降雨导致收获窗口压缩至3天的极端局面，农业农村部协调周边省份1.3万台收割机星夜驰援，一周内突击抢收1500余万亩。此外，通过实施大面积单产提升技术措施，今年小麦每亩穗数增加明显，特别是7000多万亩的旱地小麦，单产比去年大幅提升。

**A股关联分析：** 中性偏多，结构性分化明显，是本日**投资含金量最高的经济数据类条目**。需要拆开看：

（1）**对粮价与种植链是偏空的**。夏粮丰收成定局、单产提升，意味着小麦供给宽松，国内麦价上行动力不足，纯粮食贸易与种植类企业的价格弹性受抑制。历史上"夏粮丰收"公告后一周，农业种植指数多数录得小幅回调，这一规律需要重视。

（2）**对农机是明确利好的**。1700万台（套）农机具、80余万台联合收割机的投入规模，加上"智能损失监测系统""一键调整割台高低角度""履带式收割机和烘干机"的具体表述，直接印证了农机**智能化与结构升级**的产业趋势。特别是湖北3天收获窗口下1.3万台收割机跨省调度，暴露了极端天气常态化背景下**烘干设备与履带式机型**的刚性缺口，这是未来几年农机补贴的重点方向。机收损失率从常规水平降到0.7%，一亩少丢10—15公斤，按3.4亿亩冬小麦推算全国节粮潜力可观，减损技术改造有真实的经济账支撑。

（3）**对下游粮食加工是利好的**。原料供给充足、成本端稳定，面粉、食品加工、饲料企业毛利改善。

（4）**对农业社会化服务与烘干仓储是利好的**。跨省调度机制常态化，利好农机流通与服务运营商。

综上，本条目的正确读法不是"买农业"，而是**买农机智能化 + 买粮食加工成本改善**，避开纯种植与粮价弹性标的。

## 三、参照历史经验的投资策略

**历史经验参照：**

- **陆家嘴论坛政策集中发布 → 券商板块**：历史上陆家嘴论坛作为年度金融改革政策的重要发布窗口，会后首个交易日券商板块普遍出现资金抢筹，但持续性高度依赖细则落地速度。经验规律是"**首日冲高、次日分化、看细则决定第二波**"。本次证监会一次性抛出五项改革（第五套标准扩容AI、主动ETF、商业REITs、外汇期货、创业板与再融资改革），政策密度显著高于往年，券商板块的反应强度可能强于历史均值，但仍需警惕情绪透支。

- **IPO制度扩容 → 一级市场估值传导**：科创板第五套标准从生物医药扩至AI，参照2019—2021年第五套标准落地后未盈利创新药企集中上市的历史，制度打开后通常有6—12个月的项目申报与受理窗口期，期间**参股相关企业的上市平台**、**投行份额领先的券商**受益最明确；而已上市的同类标的可能因供给增加面临稀缺性溢价稀释，这一负面效应在生物医药板块历史上出现过，需引以为鉴。

- **油价快速下跌 → 交运与化工中下游**：历史上原油从高位快速回落至80美元下方的阶段，航空股通常在油价确认趋势性下行后的2—4周内录得明显超额收益，因为航油成本传导有滞后性，市场需要时间对利润弹性重新定价；化工中下游的价差改善则体现在下一个季度的财报中，属于"**先估值后业绩**"的节奏。反之，油气开采与油服板块在油价下行期几乎没有反弹机会，历史上抄底该板块的胜率很低。

- **地缘冲突缓和 → 风险偏好修复**：中东局势从紧张转向缓和的阶段，A股整体风险偏好通常改善，但军工板块承压。历史规律显示，协议签署"前夜"往往是预期最充分的时点，签署当日反而容易出现"**利好兑现**"式回调，本次美伊备忘录19日签署，需注意这一节奏。

- **夏粮丰收公告 → 农业板块**：历史上"夏粮丰收已成定局"官方表述发布后，农业种植指数多数录得小幅回调，因为丰收意味着粮价上行动力不足。真正的机会在农机（政策性补贴与更新换代）和粮食加工（原料成本改善），这一分化在历年"三夏"报道后均有体现。

- **外部技术封锁 → 自主可控**：从历史上多轮芯片、EDA、操作系统的对外限制事件看，A股自主可控板块的反应模式是"**消息当日大幅高开、随后3—5日震荡消化、若伴随国内实质性政策支持则走出第二波主升**"。本次美方限制AI模型访问叠加国内科创板AI融资通道打开，具备走出第二波的条件，但需跟踪国内配套政策的实际推进。

**规避提示：**

第一，**坚决规避石油开采与油服板块的"抄底"冲动**。油价跌破80美元且伊朗增量供给即将回归，上游盈利承压是明确的趋势而非短期扰动，历史上在油价下行初期抄底能源上游的胜率极低，不要用"跌了很多"作为买入理由。

第二，**规避在协议签署当日追涨地缘缓和受益标的**。美伊备忘录19日签署，市场对此已有充分预期，签署当日大概率是预期兑现的高点而非起点，追高容易套在情绪顶部。

第三，**规避纯农业种植与粮价弹性标的**。夏粮丰收成定局、单产大幅提升，小麦供给宽松，种植类企业缺乏价格弹性，此时买入农业股属于逆基本面操作。

第四，**规避埃博拉疫情概念的短线炒作**。海外疫情消息对A股医药股的刺激历史上普遍只持续1—3个交易日，且高开低走概率大，这类脉冲性题材参与胜率低、赔率差。

第五，**规避文艺家协会大会、记者见面会、评论员文章等纯宣传类条目衍生的"概念标的"**。这类新闻与上市公司收入无任何实质传导，市场若因此炒作纯属情绪投机，不具备可持续性。

第六，**注意科创板第五套标准扩容对存量AI标的的双面性**。制度打开融资通道利好一级市场与券商投行，但对已上市的同类AI公司而言，未来供给增加会稀释稀缺性溢价，高估值的存量AI标的需警惕估值中枢下移风险，这是历史上生物医药板块已经验证过的教训。
